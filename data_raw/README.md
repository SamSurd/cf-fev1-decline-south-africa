# data_raw

This folder is empty on purpose: the registry data are not shared with the code.

The scripts expect the South African Cystic Fibrosis Registry export for 2018–2024 here as `CF_registry_master.xlsx`, with the data in sheet `Sheet1` (one row per patient, yearly columns). The data are available on reasonable request to the SACFR steering committee, subject to ethics approval.

Do not add the data file to a public copy of this repository.
